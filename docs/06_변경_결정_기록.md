# 변경 결정 기록 (01~05 문서 이후 사용자 결정)

문서 01~05의 확정 사항 중 이후 사용자가 바꾼 결정을 기록한다. 이 문서가 앞선 문서보다 우선한다.

## 2026-11-20 — 데이터 저장과 인증

| 항목 | 기존 확정 | 변경 | 비고 |
|---|---|---|---|
| 데이터 원본 | 2단계: IndexedDB(Dexie) 로컬 저장 → 3단계: D1 동기화 | **Cloudflare D1을 바로 원본으로 사용** | 사용자 지시 "로컬 DB 말고 Cloudflare D1" |
| 인증 (Q17) | Google 계정 로그인 | **개인 접근 키** (기기마다 한 번 입력, 서버 비밀값과 비교) | 개인 사용 전용. Google Cloud 설정 불필요. 키 유출 시 서버 비밀값 교체 |
| 오프라인 (Q18) | 오프라인에서 읽기·수정 후 동기화 | **현재는 온라인 필요** (서버 연결 실패 시 저장 불가) | 기기 캐시 + 전송 대기열은 추후 단계. 저장소 계약(`src/data/store.ts`)은 캐시를 넣기 쉽게 분리 |
| 배포 형태 | Cloudflare Pages | **Cloudflare Workers + 정적 자산**(Static Assets) | Cloudflare가 새 앱에 권장하는 방식. 같은 Worker가 SPA와 `/api/*`를 함께 제공 |

## 구조 요약

- `worker/index.ts`: `/api/state`(전체 조회), `/api/batch`(원자적 변경 묶음). 모든 요청에 `Authorization: Bearer <ACCESS_KEY>` 필요, 키 미설정 시 전부 거부.
- `migrations/0001_init.sql`: `records`(컬렉션별 JSON 문서 + `deleted_at`·`rev`·시각) + `kv`(실행 중 타이머).
- `src/domain/collections.ts`: 클라이언트·서버 공통 규칙. 학습 계획끼리(Q69, Q144), 확정 공부 기록끼리(Q84) 시간 중복을 **서버에서도** 거부.
- 휴지통: `deleted_at` 표시 후 30일 지나면 서버가 영구 삭제 (Q72, Q79).
- 타이머: 서버 `kv`에 시작·휴식 시각과 소유 기기 ID만 저장 → 앱을 닫거나 다른 기기에서 열어도 경과 유지, 소유 기기 외에는 읽기 전용 (Q46 일부, Q71, Q148).

## 아직 연결하지 않은 것

- 수행평가·시험·학원·목표·학교 시간표·학습 자료의 추가/수정 폼 (화면은 D1 데이터를 읽어 표시)
- 반복 일정 수정 범위 선택(Q131), 앱 재실행 시 중단 구간 확인(Q46), 영구 삭제 후 이름 스냅샷(Q150), 시험 범위 Part 추가 확인(Q139)
- JSON/CSV 백업·복원, Google Drive, 오프라인 캐시·동기화, Android APK
